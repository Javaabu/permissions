- PHP 8.4 or higher
- Laravel 12 or 13
- [spatie/laravel-permission](https://spatie.be/docs/laravel-permission) 7.2 or higher (installed with the package)

Optional:

| Package | For |
| --- | --- |
| [spatie/laravel-activitylog](https://spatie.be/docs/laravel-activitylog) ^4.10 | [Logging role and permission changes](advanced-usage/activity-log.md) |
| [inertiajs/inertia-laravel](https://inertiajs.com) ^2.0 | Rendering the [role pages](basic-usage/managing-roles.md) with Inertia React |
